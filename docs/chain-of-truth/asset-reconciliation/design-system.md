# Design System Delta

Status: Reviewed

Fitur memakai komponen Filament 4 yang sudah ada. Badge hijau berarti Inline, kuning berarti Gap, merah berarti Terblokir, dan biru berarti Diterapkan. Label aksi menomori tahap pipeline: `0. Export Format CSA`, `1. Import Audit CSA`, `2. Laporan`, dan `3. Terapkan Koreksi`. Subheading halaman menjelaskan langkah berikutnya. Apply berwarna danger, wajib konfirmasi, dan disabled saat ada baris Terblokir. Kolom utama selalu menampilkan Gudang, Barang/Item, saldo Shelf, target, gap, status, dan penjelasan; kolom diagnostik dapat di-toggle. Label menggunakan istilah audit pengguna: Gudang, Saldo Real, Koreksi, dan Gap Shelf.
